# Jim's Garage

Here's a collection of Docker Compose and config files for use in my videos. Simply tweak to your environment and deploy!

## About this fork

This is my fork of [James Turland's JimsGarage repository](https://github.com/JamesTurland/JimsGarage). I'm using it to explore homelab setups, self-hosted applications and the configuration of services running in Docker environments.

The repository covers a wide range of services and infrastructure, including:

- **Self-hosted applications** — media servers, productivity tools and personal services.
- **Networking & remote access** — VPNs, tunnels, DNS and reverse proxies.
- **Monitoring & security** — dashboards, metrics, authentication and security tools.
- **Infrastructure** — Docker, virtualisation, storage, automation and server management.

The configurations are intended as starting points. Review the relevant files and adapt settings, paths, credentials and network details to your own environment before deploying anything.
